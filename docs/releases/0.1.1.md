# Silk 0.1.1

One installer now automatically prepares everything needed for compressed clip
sharing. Users no longer need to install FFmpeg or configure any paths.

- First setup automatically downloads and verifies the approved sharing tools
  (about 240 MB). Internet is required. WebView2 is also installed if missing.
- Existing verified sharing tools are reused without another download.
- Interrupted or invalid downloads stop setup with an error; rerun setup to retry.
- Saved clips and settings are retained when updating from 0.1.0.

This release has no Windows publisher (Authenticode) signature. Windows may
warn or block execution under stricter security policies. The separate updater
signature remains enabled and verified.

Download and run Silk_0.1.1_x64-setup.exe, or use Update & restart in Silk.
Setup and export were tested on the development Windows machine with an empty
dependency directory; a clean Windows VM and other hardware remain unverified.
