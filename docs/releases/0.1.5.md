# Silk 0.1.5

- DXGI-only game and window capture, with automatic/manual game selection and
  frozen-frame continuity when switching away from the game.
- Recovery improvements for fullscreen/display transitions.
- Automatic target labels identify the attached capture session instead of Desktop.
- Audio/video clock correlation preserves startup waits and audio recovery time.
- MP4 audio timing preserves pauses rather than concatenating them away.
- Theme-aware capture status, saved-clip feedback and native overlay.
- Named custom color presets and independent app icon colors, applied only on save.
- Cleaner capture controls and filtered system-helper windows.

Windows publisher signing remains temporarily unavailable under the approved
0.1.5 exception. Updater artifacts remain cryptographically signed and version-bound.

Validation includes automated workspace/browser checks and local DXGI/WASAPI decoded
flash/tone acceptance within 100ms after simulated recoveries. Hardware coverage is
limited to the tested machine; this is not a frame-perfect synchronization guarantee.
