# Silk 0.1.0

The first public Windows release of Silk: local instant replay recording and clip review.

- Desktop capture through DXGI Desktop Duplication, with a bounded replay buffer.
- Separate audio tracks and selectable Windows audio devices, including GoXLR channels.
- Configurable capture and player hotkeys.
- Standard, theater, and fullscreen clip playback, previous/next navigation,
  hover controls, seeking, speed controls, and automatic fullscreen opening.
- Favorites, game filters, VOD review timestamps, comments, and marker colors.
- Theme-aware tray/taskbar icons and customizable interface colors.
- Original-file drag and drop into Discord or other applications. Optional
  FFmpeg tools enable 10, 50, and 100 MB share copies with a thumbnail preview.
- Configurable capture HUD and clip-save sound volume.
- Signed application updates with download progress and automatic restart.

## Install and update

Run `Silk_0.1.0_x64-setup.exe` on Windows 10 (1903+) or Windows 11, x64.
The installer installs for the current Windows user. It may download WebView2
if that runtime is missing.

Silk checks for newer releases on launch and every four hours. Use Settings →
System to check manually or disable automatic checks. When a newer version is
available, **Update & restart** downloads and verifies it, installs it, and
reopens Silk. Saved clips and settings remain; save any replay you need before
updating because the in-memory buffer starts fresh after restart.

## Notes

- Size-limited share copies require the separately installed, approved FFmpeg
  and FFprobe tools listed in `THIRD_PARTY_LICENSES.md`. Original-file sharing
  works without them; those tools are not included in this installer.
- Capture records the selected display. Foreground game naming is best effort;
  this release does not inject into games or use graphics hooks.
- Native capture/audio and updates were exercised on the development Windows
  machine. Clean-machine installation, other hardware combinations, and
  eight-hour endurance remain unverified.
